E.164 format for US and international numbers

E.164 writes a phone number as a plus sign, the country code, then the rest of the number, with no spaces or punctuation. So the US number (202) 555-0142 becomes +12025550142, and this is the form Twilio expects.

What E.164 looks like

E.164 is the international numbering plan from the ITU, the UN body for telecoms. It gives every public phone number one unambiguous written form, which is why software uses it. Per Twilio's E.164 glossary page, a number must:

  • start with +
  • use only digits after that, with no spaces, dashes, dots or brackets
  • have 15 digits at most, including the country code
  • never have 0 as the first digit, because no country code starts with 0

Reading left to right, +12025550142 breaks down like this:

PartIn this numberNotes
Plus sign+Marks the number as international
Country code1One to three digits
Area or national code202Length varies by country
Subscriber number5550142The rest of the digits

E.164 format for US phone numbers

A US number is always +1 followed by 10 digits, 12 characters in all. Every common way of writing the same number converts to one result. Canada shares country code 1, so it works the same way. The numbers below are in the 555-01xx range set aside for fiction.

E.164 examples for international numbers

Outside North America, there's one more step. Many countries write a leading 0 for calls inside the country, and that 0 isn't part of the international number. Twilio gives the UK as its example: remove the 0, then add the plus and country code. The examples below come from ranges that Ofcom and ACMA reserve for fiction.

UK mobile07700 90012344+447700900123

How to convert any number to E.164

  1. Find the country. You can't convert a number without knowing it. 029 2018 0123 means nothing to Twilio on its own.
  2. Strip everything except digits. Remove spaces, dashes, dots and brackets. Set any extension aside.
  3. Remove any international dialing prefix. Someone may have written 011 from the US or 00 from elsewhere. Those are instructions to a phone, not part of the number.
  4. Deal with the leading 0. If the number uses a national 0, as in the UK and Australia, drop it. If you aren't sure about a country's rule, let Lookup decide (see below) rather than guessing.
  5. Add the plus and country code. Don't add the code twice, which is easy to do when a number already starts with it.
  6. Count the digits. A US number has 11 after the plus. Anything over 15 can't be right.

Which mistakes cause Twilio errors?

What you seeLikely cause
Error 21211, invalid To numberMissing plus or country code, punctuation, or a digit too many or too few. It also appears if To and From are the same Twilio number
Error 21212, invalid From numberThe sender isn't written correctly. Check it for the same formatting problems
Error 21614, not a mobile numberThe format can be fine, but the number may be a landline that can't get texts
Error 13224 in a DialA missing plus or country code in TwiML, or a destination Twilio can't route

Three quieter traps are worth checking when numbers come from somewhere else:

  • Spreadsheets. A spreadsheet can treat +12025550142 as a number or a formula, dropping the plus or showing it in scientific notation. Format the column as text before you paste.
  • Hidden characters. Numbers copied from a web page or contact card can carry invisible formatting characters. If a number looks right but fails, retype it.
  • URL encoding. In form data, a raw + can be read as a space, so your number arrives without it. Encode it as %2B or let your tool do it:

Store one format

Save numbers in E.164 and format them only for display. Comparing or de-duplicating contacts gets much easier, and it means the numbers you hand to Twilio's SMS API are already in the right form.

Questions

What is the E.164 format for a US phone number?
A plus sign, the country code 1, then the 10-digit number with no spaces or punctuation. For example, (202) 555-0142 becomes +12025550142.
Does E.164 always start with a plus sign?
Yes, as Twilio writes it. Twilio's glossary lists the + as part of the format, and its API expects it on To and From phone numbers.
How long can an E.164 number be?
Up to 15 digits, counting the country code but not the plus sign. Country codes are one to three digits long, and many numbers are shorter than the maximum.
How do I add an extension to an E.164 number?
You can't. E.164 only contains digits after the plus, and there's no place for an extension. Store the extension separately. On a Twilio call, you'd press those digits after the call connects.
Can a regex confirm a number is valid?
Only its shape. Twilio's docs warn that a regular expression can't guarantee a valid number. Use it to catch typos, then use the free Basic Lookup to check the number itself.
