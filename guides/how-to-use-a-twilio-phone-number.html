How to use a Twilio phone number

You use a Twilio number by telling Twilio what to do with it: API requests or an app send texts and place calls, and settings on the number decide where incoming calls and texts go. It has no SIM and doesn't ring anywhere until you set that up.

How is a Twilio number different from a normal phone number?

A SIM number is tied to one phone, so calling and texting just work. A Twilio number is more like a programmable switchboard. Other people can call and text it like any number, but you decide what happens next. That takes a little setup, and in exchange it can forward to any phone, read a message aloud or reply automatically.

How do I set up a Twilio phone number?

  1. Upgrade and buy a number. Trial numbers are shared, so upgrade your account first. In the Console, go to Communications, then Numbers & senders, then Phone Numbers, and choose Set up a new phone number. In the legacy Console, it's Phone Numbers, then Manage, then Buy a number.
  2. Set what happens on incoming calls. Open the number's voice configuration and point incoming calls at a TwiML Bin or webhook URL. To forward calls, use TwiML that dials your own phone.
  3. Set what happens on incoming texts. Open the number's messaging configuration and point it at a webhook or TwiML Bin, or simply read replies in the Console's message logs.
  4. Register for US texting if you need it. If you'll text US phones from a local number, complete A2P 10DLC registration and attach the number to a Messaging Service. Toll-free numbers need toll-free verification instead.
  5. Make your first call or text. Send a request to Twilio's API with your number in the From field and the other person's number in the To field, both in E.164 format, or use an app that makes those requests for you.

A US local number is $1.15 a month, as of November 2026 (Twilio voice pricing). See how much a Twilio number costs for the other types. Numbers outside the US and Canada usually need an approved regulatory bundle before you can buy them. Twilio's phone number setup guide has the current Console steps.

How do I receive calls and texts on a Twilio number?

When a call or text arrives, Twilio looks up the instructions you set on that number. Those instructions are TwiML, a short XML format. You can host it on your own server, or skip the server and use a TwiML Bin, which Twilio hosts for you. This one forwards every call to your cell:

Create the Bin, then select it in your number's voice configuration for incoming calls. Our Twilio call forwarding guide covers caller ID, timeouts and fixes. If you use a webhook on your own server, it has to answer quickly: Twilio allows 10 seconds to connect and 15 seconds in total, and a failure shows up as an error such as 11200.

Texts work the same way with a messaging webhook. If you don't set one, you can still see incoming messages in the Console's logs, or read them over the API.

US texts need registration first

Sending to US phones from an unregistered local number fails with error 30034. Complete A2P 10DLC registration first. Twilio requires a Messaging Service for numbers subject to A2P 10DLC.

How do I use a Twilio number without writing code?

You have three no-code options, and they each cover part of the job:

  • The Twilio Console handles buying, forwarding with TwiML Bins, and reading logs. It isn't designed for day-to-day conversations.
  • Hosted business-phone services bundle a number and an app for a monthly fee. That's simplest if you don't want a Twilio account at all.
  • An app on your own Twilio account. Dialbubble is a free iPhone app for this. It sends texts and places calls using your number, as explained on how Dialbubble works. It has no in-app VoIP, so Talk calls ring your regular phone and bill two legs. It doesn't answer incoming calls, so you still set up forwarding at Twilio. For texts, see how to send SMS from iPhone with Twilio.

Questions about using a Twilio number

Can I put a Twilio number in my phone like a SIM?
No. A Twilio number lives on Twilio's network with no SIM behind it. You reach it through the Console, the API or an app, and incoming calls can be forwarded to any phone you choose.
Can I use a Twilio number for WhatsApp or to receive verification codes?
Twilio supports WhatsApp senders, with their own setup. Don't count on using a Twilio number for sign-up codes from other services, because many services decide for themselves which number types they'll accept.
Why does nothing happen when someone calls my number?
Usually no voice URL or TwiML Bin is set, or the URL is failing. Check the number's voice configuration, then look in the call logs. Webhook failures show up there as errors such as 11200.
Do I have to write code to use a Twilio number?
No. You can forward calls with a TwiML Bin in the Console and pick up messages in the logs. To send texts and place calls without code, you'll want an app that connects to your Twilio account.
