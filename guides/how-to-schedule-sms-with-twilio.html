How to schedule SMS with Twilio

To schedule an SMS with Twilio, create a message through a Messaging Service and add ScheduleType=fixed and a SendAt time in UTC. Twilio holds the text and sends it at that time, as long as it's between 15 minutes and 35 days away.

What do you need before you schedule?

Twilio's Message Scheduling is built into the Messaging API, and the docs say it comes at no extra cost. You only pay for messages that are sent. Before you start, check these three things:

  • A paid account. On a trial, you can only send predefined templates to verified numbers. Our page on Twilio trial limits explains what's blocked.
  • A Messaging Service. This is a Twilio settings group that holds your senders. Scheduling doesn't work from a bare number.
  • A number allowed to send. For US texts from a local number, you need A2P 10DLC registration, so do that first. Twilio accepting a scheduled text doesn't prove it will go out, because some failures only appear at the send time.

How to schedule a text, step by step

The commands use API key credentials stored in environment variables, and fictional numbers.

  1. Create a Messaging Service. Use the Messaging section of the Console, or the Services API. Note the SID in the response, which starts with MG.
  2. Add your number to the sender pool. You'll need your number's SID, which starts with PN. Skip this and you risk error 21703, meaning no sender is available.
  3. Convert your send time to UTC. Say you want Monday, November 9, 2026, at 9:00 AM in Los Angeles. Pacific Time is UTC-8 on that date, so the value is 2026-11-09T17:00:00Z.
  4. Create the message. It's a normal send with two extra parameters. Note that there's no From here, as the service picks the sender.
  5. Save the SID and check the status. You should see scheduled. An empty from, 0 segments and no price are all normal at this stage, since nothing has been sent.

At the send time, the status moves to queued, and from there it follows the same path as any other text. Our guide to how Twilio SMS works explains each status after that. If you've set a status callback URL, Twilio posts each change, but not the first scheduled status, so read that one from the response.

How do you get the send time right?

Most scheduling mistakes are time mistakes. SendAt should be a UTC timestamp in the form YYYY-MM-DDTHH:MM:SSZ. The final Z means UTC. The offset you need is the one on the day the text goes out, not the one today.

You wantOffset that daySendAt
Nov 9, 2026, 9:00 AM Los AngelesUTC-8 (PST)2026-11-09T17:00:00Z
Nov 9, 2026, 9:00 AM New YorkUTC-5 (EST)2026-11-09T14:00:00Z
Nov 9, 2026, 9:00 AM LondonUTC+0 (GMT)2026-11-09T09:00:00Z

The daylight saving trap

Clocks in the US go back on November 1, 2026. If you schedule on October 30 for 9:00 AM Pacific on November 2 and use October's UTC-7 offset, you get 16:00Z, and the text goes out at 8:00 AM. Use the offset for the send date, ideally with a date library rather than by hand.

Think about the recipient's time too. A 9:00 AM New York text reaches Los Angeles at 6:00 AM. If you have a list across time zones, create separate messages for each zone.

If you're generating timestamps in code, leave some margin. A send time set exactly 15 minutes ahead can drop out of the window while the request is on its way.

How do you cancel a scheduled text?

Update the message with the SID you saved, and set its status to canceled. Do it before the send time.

The response should show canceled. To change the wording or time, cancel the message, create a new one, and keep the new SID. If you lost the SID, you can list messages in the Console logs or with the API, then look for the ones in scheduled status.

Sent immediately by accident?

Twilio's docs warn that without MessagingServiceSid, a message can be treated as non-scheduled and sent right away. Test with your own phone first.

What doesn't Twilio scheduling do?

  • Recurring sends. The only schedule type is fixed, a single time. For a weekly text, create each one separately or run your own job.
  • Promise delivery. A scheduled text can be accepted now and still fail at the send time, such as when the recipient has opted out.
  • Long-range planning. For anything further than 35 days away, store it yourself and create the scheduled message once it's inside the window.

Can you schedule a text without code?

Scheduling is an API feature, so you need something to make the request. curl works, as above, and so does any tool that can post to a URL. On an iPhone, you can do the same with a Shortcut or an app, as covered in sending SMS from an iPhone with Twilio. Whichever you use, the rules are the same: a Messaging Service, and a time 15 minutes to 35 days away.

Questions

Does Twilio charge extra to schedule a message?
No. Twilio's docs say scheduling comes at no cost and you only pay for the messages sent. A canceled message is not sent.
Can I schedule a text without a Messaging Service?
No. Without MessagingServiceSid, Twilio treats the request as a normal message and sends it, or returns error 35118 if it spots the scheduling parameters. Passing only From isn't enough.
How far ahead can I schedule an SMS on Twilio?
Twilio's scheduling docs set the window at 15 minutes to 35 days between your request and the send time.
Can I edit a scheduled message?
The documented option is cancellation, by setting its status to canceled. To change the wording or time, cancel it and create a new one, then save the new SID.
What happens if the person opts out after I schedule?
The scheduled message stays in place and fails at its send time. Twilio suggests canceling any remaining scheduled messages to that person.
