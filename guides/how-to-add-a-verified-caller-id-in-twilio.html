How to add a verified caller ID in Twilio

Add the number under Verified Caller IDs in the Twilio Console, then answer the call Twilio places to it and enter the six-digit code. After that you can show the number as your caller ID on outbound calls, though not on texts.

What is a verified caller ID in Twilio?

It's a phone number you already own, outside Twilio, that you've proven you control. Twilio keeps a list of these on your account, and the OutgoingCallerIds docs describe them as numbers you can use as caller ID on outgoing calls, through either the API or TwiML <Dial>.

It's useful when people already know your number. Your office line or mobile can appear on calls that Twilio places, so call-backs reach you there and you don't have to hand out a new number. Only verify numbers you own or are authorized to use. Our guide to what outbound caller ID is explains the wider rules.

How do you add a verified caller ID in the Console?

Twilio is moving between two versions of its Console, so the labels may differ a little from these.

  1. Have the phone next to you. Twilio calls right away. Turn off call screening or silencing of unknown callers for now, or the call may never ring.
  2. Open Verified Caller IDs. Look under Numbers & senders, or Phone Numbers in the legacy Console. You need the right account, because verified numbers belong to one account.
  3. Add the number. Choose to add a new caller ID and enter it in E.164 format, such as +14155550111.
  4. Answer the call and enter the code. Twilio shows a six-digit code and calls the number. Twilio's verification docs say the call comes from +1 415 723 4000 and is in English only. Enter the code on the keypad when asked.
  5. Test it. The number now appears on your list. Make a test call, as shown below, and check what the other phone displays.

How do you add one with the API?

Send a request to the OutgoingCallerIds endpoint. Adding by API has the same result as using the Console. The response includes the code you need, and the call comes in right after.

Read validation_code in the response and enter it when the phone rings. If you're verifying a number behind a switchboard, the API has two helpful options: Extension holds digits to dial after connecting, and CallDelay waits up to 60 seconds before calling, which gives you time to get to the phone.

How do you use a verified number on a call?

Here's a typical case. Sam is a consultant whose clients all know her office line, +1 415 555 0111. She verifies it, then makes calls from her mobile, +1 415 555 0177, through Twilio. Clients see the office line and their call-backs go to the office. Her request looks like this:

Twilio rings Sam's mobile first, then dials the client. That makes two legs, so a 10-minute US call costs 10 × 2 × $0.0140 = $0.28, using the $0.0140 per minute rate on Twilio's US voice pricing, as of November 2026. Fifty of those a month is $14.00. She isn't renting the office number from Twilio, so there's no $1.15 number fee for it, but a Twilio number would add attestation and texting options, as covered below.

Sam's request needs an upgraded account, because Twilio's trial docs list <Dial><Number> as blocked during a trial.

Dialbubble can use a verified number as the caller ID on calls too, if you prefer buttons to curl. Its two-way calls ring your regular phone in the same way and bill the same two legs.

Why isn't my verified caller ID working?

Most problems fall into one of these. Work through whichever matches what you see.

The verification call never ringsCall screening, a blocked unknown caller or a carrier filterTurn off screening, allow +1 415 723 4000, and check Twilio's call logs to see if the call went out
A number abroad won't verifyYour account can't dial that countryEnable it in Voice Geo Permissions first, as Twilio requires

What can't a verified caller ID do?

  • Send texts. Twilio says verified numbers can't send SMS or MMS. To text, you need a Twilio number that can send SMS, and in the US A2P 10DLC registration too.
  • Receive calls through Twilio. Call-backs go to the phone you already had. Twilio isn't involved, so a TwiML Bin won't run on them.
  • Reach the top US trust level. Twilio's SHAKEN/STIR docs say level B is the highest possible for non-Twilio numbers, because Twilio can't attest to your right to use them. A Twilio number can reach level A.

So when should you verify a number, and when should you buy one? Verify when people already know the number and you only need to show it on calls you place. Buy a Twilio number when you want to text from it, take incoming calls through Twilio, or get the higher trust level. Plenty of people do both: a verified office line for familiar clients, and a Twilio number for everything else. The cost of a purchased number is covered in how much a Twilio phone number costs.

Two uses of the word verified

On a Twilio free trial, you also verify the people you call and text, up to 5 per account. That's a different purpose for the same word: on a trial, verifying someone's number lets you reach it, while a caller ID is the number other people see when you call.

Questions people ask

How do I remove a verified caller ID?
Delete it from the Verified Caller IDs list in the Console, or send a DELETE request for its OutgoingCallerIds SID in the API. Twilio then stops accepting it as a caller ID on that account.
Can I verify someone else's number?
Only with their authorization, such as a company line you're allowed to use. Showing a number you have no right to use can break the law and Twilio's terms, even if someone reads you the code.
Do I need a Twilio number if I've got a verified one?
Not to show it on outbound calls. You'll want a Twilio number to text, to receive calls through Twilio or to forward them.
Does the verification call work in other languages?
No. Twilio says the verification call is in English only. The code itself is just six digits, so you can enter it either way.
