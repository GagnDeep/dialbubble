How to get a Twilio Account SID and Auth Token

Your Account SID is on the Twilio Console's account home, and your Auth Token is on the API keys & auth tokens page under Settings, hidden until you select the eye icon. Copy both from the same account and you're ready to make requests.

Where do I find my Twilio Account SID and Auth Token?

Twilio is moving people to a new Console, so you may see either of two layouts. These steps cover both. If a menu name has moved again, type "API keys" into the Console search bar.

  1. Log in to the Twilio Console. Sign in at 1console.twilio.com. If your account still opens the legacy Console at console.twilio.com, the same details are there under slightly different menu names.
  2. Copy your Account SID. Your Account SID is shown on the Console's account home or dashboard. It starts with AC and is 34 characters long. It isn't secret on its own, so it's normally visible without an extra click.
  3. Open the API keys and tokens page. In the current Console, go to Settings, then Account settings, then API keys & auth tokens. In the legacy Console, go to Admin, then Account management, then API keys & tokens.
  4. Check the region. Pick your region on that page. Twilio's API credentials are region-specific. Most accounts use the default United States region unless someone set up Twilio Regions.
  5. Reveal and copy the Auth Token. The token is hidden by default. Select the eye icon to show it, then copy it straight into wherever you store secrets, such as an environment variable or a password manager.
  6. Test the pair. Run a simple read request with the SID as the username and the token as the password. A JSON reply describing your account means the pair works. An authentication error means one of the values is wrong.

Twilio documents the current path in its guide to API keys in the Console. Haven't signed up yet? A new account starts as a trial, and our guide to what the Twilio free trial includes and blocks explains what you can do before paying.

What does a Twilio Account SID look like?

Twilio publishes the exact format of a SID: two letters that show the type of resource, then 32 hexadecimal characters. That makes mistakes easy to spot. These examples are fake and won't work.

CredentialFormatFake example
Account SIDAC + 32 hex charactersACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
API key SIDSK + 32 hex charactersSKxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Auth TokenNo prefix, no published patternTWILIO_AUTH_TOKEN (keep it in a variable)

Twilio's Accounts reference defines the Account SID pattern, but it describes the token only as a secret string, so don't expect a prefix to check. To test the shape of what you copied, use the Twilio credentials format checker, which runs entirely in your browser.

The usual copy mistakes

A stray space at either end, an API key SID (SK) pasted where the Account SID (AC) belongs, or a token from a different subaccount. Check those three before anything else.

A 401 reply with code 20003 means the pair was rejected. Our page on Twilio error 20003, authentication failed goes through the causes.

How do I change my Twilio Auth Token?

Rotate your token if it may have leaked, if someone with access has left, or as routine upkeep. Twilio gives you a secondary token so you can do this without downtime. Do the steps in this order, because promoting removes the old token straight away:

  1. On the API keys and tokens page, request a secondary Auth Token.
  2. Reveal it and update every app, script and device that uses the old token.
  3. Confirm each one still works, using the secondary token.
  4. Select Promote to Primary. The new token becomes the main one and the old one stops working.

You can do the same with the Secondary Auth Token and Auth Token promotion endpoints. Two details from Twilio's docs are worth knowing. Every token change emails all owners and administrators on the account, so a surprise email of this kind deserves a look. And if you hard-coded the token in Twilio Functions, allow one minute for the change to spread, or those functions will fail with a 403.

How do I keep them safe?

The Account SID and Auth Token together give full access to your account, including your balance and your numbers. A few habits cover most of the risk:

  • Keep them out of source code. Use environment variables or a secrets manager, and add any local .env file to .gitignore.
  • Never paste them into a website you don't trust, a support ticket or a chat.
  • Use API keys for your applications, which is what Twilio recommends. You can revoke one key without touching the others. See Auth Token vs API Key for how to choose.
  • If you think a token leaked, rotate it now, then check your usage logs for calls and texts you don't recognize.

If you use the credentials with a phone app, check where they're stored. Dialbubble keeps them in the iPhone Keychain and talks only to Twilio. Our security page explains how that works.

Why isn't my Auth Token working?

  • Mismatched account: the SID and the token came from different accounts or subaccounts.
  • Old token: someone promoted a secondary token, so the one you saved no longer exists.
  • Wrong region: credentials are region-specific, so ones made for another region can fail against the default API.
  • Test credentials: Twilio's test credentials never reach real phones and can't touch your live numbers, so real sends with them won't work.
  • Suspended account: if your balance ran out or the account was suspended, sort that out in the Console first.

Questions about your Twilio credentials

Is the Twilio Account SID secret?
Treat it as private but not as a password. It identifies your account and appears in API URLs, so it can't sign anyone in by itself. The Auth Token is the real secret. Anyone holding both can use your account and spend your balance.
Do subaccounts have their own SID and Auth Token?
Yes. A subaccount is its own account resource with its own SID and token. A common cause of error 20003 is pairing a SID from one account with a token from another, so copy both from the same account.
What happens to my Account SID when I upgrade from a trial?
Nothing. Twilio keeps the same Account SID and Auth Token when you upgrade, so anything already set up with them keeps working.
Can I recover an API key secret I lost?
No. Twilio shows an API key's secret only once, when you create it. If you lost it, create a new key, update whatever used the old one, and revoke the old key.
