TwiML examples you can copy and use

TwiML is the short XML that tells Twilio what to do on a call or text, such as say this, dial that number, or record a message. Below are working examples for each common job, and you can run them in a Twilio-hosted TwiML Bin without a server.

What is the TwiML format?

A TwiML document has one root element, <Response>, with verbs inside it that Twilio runs from top to bottom. Twilio's TwiML docs note that verb and attribute names are case sensitive, so <Say> works and <say> doesn't. Every example here has been written against the current verb docs, and uses example numbers and URLs that you'll need to replace.

Where do you put TwiML?

The easiest place is a TwiML Bin, which Twilio hosts for you. Create one under Developer tools in the Console, paste the XML and save. Then open your number's configuration, find "A call comes in" under Voice, choose TwiML and select your Bin. Text replies go in the matching messaging setting.

You can also send TwiML with an outgoing call, using the Twiml parameter of the Calls API, which has a 4,000-character limit. Dialbubble's Custom TwiML call mode uses this approach. Note that any action URL must be absolute when you do this. If you'd rather not write XML by hand, our TwiML builder assembles it in your browser.

Example: read a voice message

<Say> turns text into speech. The voice and language attributes are optional, and if you leave out voice, your account's text-to-speech default applies. <Pause> waits for the number of seconds you set, and <Hangup> ends the call.

What 200 reminder calls cost

Twilio bills calls by the minute, so count a 30-second reminder as one minute. At $0.0140 per minute for US outbound, as of November 2026, 200 answered calls come to 200 × 1 × $0.0140 = $2.80. Calls that go unanswered aren't charged, but a voicemail that picks up is.

Example: play an audio file

<Play> fetches an audio file from a public URL and plays it. loop sets how many times. A value of 0 repeats until the caller hangs up or 1,000 plays are done, so be careful with it, because you pay for those minutes.

Example: forward a call with Twilio Dial

<Dial> connects the caller to another number. timeout sets how long it rings, with a default of 30 seconds and a minimum of 5. Twilio adds about 5 seconds on top. When the dial finishes without an action, Twilio moves to the next verb, so the <Say> plays if nobody answers.

To ring several phones at once, nest up to ten <Number> nouns. The first to answer wins and the others stop ringing.

Caller ID, voicemail fallback and cost all need more detail than fits here, so see how to set up Twilio call forwarding. Forwarded calls bill two legs.

Example: a phone menu with Gather

<Gather> collects keypad presses or speech. Here it plays the menu, waits up to 6 seconds for one digit, and posts the result to your action URL as a Digits parameter. Without an action, Twilio requests the same document again, which usually means a loop.

Example: voicemail with Record

<Record> captures the caller and then requests your action URL with a RecordingUrl parameter. By default it stops after 5 seconds of silence and allows up to an hour, so set maxLength to something sensible. The action matters because without one, Twilio re-requests the same document and the caller goes around again.

Recording adds its own charges and legal duties. Read about Twilio call recording cost and consent first.

Example: reject a call without being billed

Twilio's Reject docs say that using <Reject> as the first verb is the only way to stop Twilio answering a call, and that any other response is an answered, billed call. Use reason="busy" for a busy signal, or leave it out for the default not-in-service response.

Example: hand off to another document

<Redirect> tells Twilio to fetch a different TwiML document and carry on from there. It's a tidy way to reuse a greeting across several numbers, or to chain Bins together, since every Bin has its own URL. Any verbs after it are ignored, so make it the last thing in the document.

What TwiML works on a trial account?

Less than you might expect. Twilio's trial docs list <Record>, <Start><Recording> and <Dial><Number> among the blocked verbs, and replace each with a spoken message saying it isn't available. That means the forwarding and voicemail examples above need an upgraded account. <Say>, <Gather> and <Play> are supported with some limits, and <Pause>, <Hangup> and <Reject> pass through unchanged. If an example here speaks a surprising message on a trial, that's the likely reason.

Which TwiML errors should you watch for?

ErrorUsual causeFix
12100 Document parse failureUnclosed tag, unquoted attribute, or a raw &Write &amp; for an ampersand, and leave nothing before the XML header
12200 Schema validation warningA misspelled verb, the wrong case, or an unknown attributeCompare the line it names with the verb's docs
11200 HTTP retrieval failureYour action or webhook URL returned an error or can't be reachedOpen the URL yourself, and make sure it accepts POST

Also note that a TwiML response can be at most 64 kB, and that the Console's error logs show the exact line that caused a parse failure or warning, which is usually faster than rereading the XML by eye.

Questions people ask

What is a TwiML Bin?
A TwiML Bin is a piece of TwiML that Twilio hosts for you at its own URL. You don't need a server, so it suits fixed replies, simple forwarding and prototypes. It can fill in values from the request, but it can't make real decisions.
Do I need the XML header line?
It's good practice to include it, and Twilio's examples do. If you include it, make sure there's no blank line or space before it, because that's a known cause of error 12100.
Can TwiML start a call by itself?
No. TwiML only says what happens during a call or in reply to a message. Something else has to start the call, such as an API request, an app or someone dialing your number.
Why does my Gather keep repeating?
Probably because there's no action attribute. When the caller enters input and no action is set, Twilio requests the current document again and the menu restarts. Point action at a different URL, and add a verb after the Gather for when nothing is pressed.
