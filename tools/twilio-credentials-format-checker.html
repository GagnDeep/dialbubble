Twilio credentials format checker

Check whether a Twilio Account SID, API key SID or token has the right format. This runs entirely in your browser and only checks the shape of the text, so it can't tell you whether a credential works.

Don't paste a live Auth Token here, or anywhere you don't fully trust. This page only checks the shape of what you type, in your browser. It sends nothing, saves nothing and never tells you whether a credential works. If you've pasted a token somewhere you shouldn't have, rotate it in the Twilio Console.

A correct format doesn't mean a credential is valid, active or yours. Only a request to Twilio can show that, and this page never makes one.

A safer home for your credentials

Dialbubble keeps your Twilio credentials in the iPhone Keychain, sends them only to Twilio, and has no server of its own. It's happy to use an API key, and Demo Mode needs no credentials at all.

What format do Twilio credentials use?

An Account SID is AC plus 32 hexadecimal characters, 34 in total. An API key SID is SK plus 32 hexadecimal characters. An Auth Token and an API key secret are each 32 characters. Hexadecimal means only the digits 0 to 9 and the letters a to f.

Account SIDAC + 32 hexNo, but keep it private
Auth Token32 charactersYes
API key SIDSK + 32 hexNo, but keep it private
API key secret32 charactersYes, and shown only once

Every Twilio resource has a SID with a two-letter prefix that tells you its type. CA is a call, SM is a message, MG is a Messaging Service and PN is a phone number. So if you paste one of those into the Account SID field, this tool can tell you what you've actually got. Our guide to finding your Account SID and Auth Token shows where each value lives in the Console.

Is it safe to paste my Auth Token here?

You shouldn't need to, and we'd rather you didn't. A format problem can be spotted from the Account SID or by counting characters, and you can test how the check behaves with a made-up value. The token is the key to your account and your money, so the habit worth building is to never paste it into any web page.

To be clear about what this page does: the check is a few lines of code in your browser. The fields aren't saved, they're never added to the URL, and the site's content security policy blocks connections to other servers. We've also marked the fields to discourage password managers from storing them. But you can't verify all of that at a glance on any website, including this one, which is exactly why the habit matters.

How do I fix “account SID is required”?

This family of errors usually means your code didn't receive the credential, and not that the credential is wrong. Work through these in order.

  • The environment variable isn't loaded. If your code reads TWILIO_ACCOUNT_SID and it's empty, the SDK has nothing to use. Twilio's Node helper reports this as username is required, since the SID is the username for basic authentication. Check that your .env file is being read and that the variable name matches exactly.
  • An API key is in the Account SID slot. The Node helper reports accountSid must start with AC. If what you passed starts with SK, you also have to give the Account SID as a separate option, as in the example below.
  • The value has picked up extra characters. Quotes in a .env file, a trailing newline or a space from copying are all common. The checker above flags these.
  • You still have a placeholder. ACXXXXXXXX and your_auth_token come from sample code, and the checker flags those too.

If the format is right and Twilio still rejects it, you'll probably see an authentication error rather than a format error. Our list of Twilio errors explains the codes in plain English.

Questions

What does a Twilio Account SID look like?
It's 34 characters: the letters AC followed by 32 hexadecimal characters. A made-up example with the right shape is ACaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa. Twilio's sample code often shows ACXXXXXXXX instead, which is a placeholder that won't work.
Is the Account SID a secret?
It isn't a password, because it can't authenticate you by itself, and it appears in every API URL. It does identify your account, so it's still best not to post it publicly. The Auth Token and API key secrets are the true secrets, and they should never be shared.
Where do I find my Auth Token?
In the Twilio Console, on the account dashboard, in the Account Info section. Our guide on finding your Account SID and Auth Token has the full steps.
Should I use an Auth Token or an API key?
An API key, where you can. Twilio's docs call API keys the preferred way to authenticate with its REST APIs. You can create one for each app or person, restrict what it can do, and revoke it without affecting anything else. Rotating an Auth Token affects everything that uses it.
Does a pass here mean my credentials work?
No. This page only checks the format. A deleted key, a suspended account or a token that was rotated yesterday all pass as long as their shape is right. Only a real request to Twilio can show whether a credential works, and this page never makes one.
What should I do if I've leaked my Auth Token?
Rotate it in the Twilio Console straight away, then update everything that uses it. Check your usage and logs for activity you don't recognize. Removing a token from a code commit isn't enough, because it stays in the history and may already have been copied.
