What does this E.164 formatter do?

It turns numbers like (415) 555-0100, 020 7946 0958 and 011 61 491 570 156 into the single format Twilio and most other phone APIs expect: a plus sign, a country code and the national number, with nothing else. Our guide to the E.164 phone number format covers the standard itself. This page does the conversion for you, in bulk.

Sending a number in the wrong format is a common cause of failed calls and texts. If you've hit a Twilio error saying a To number is invalid, the format is the first thing to check.

How it reads each number

Phone numbers are ambiguous, so the formatter works through these steps in order and tells you in the notes column what it decided.

  1. Clean up. It removes spaces, dashes, dots and brackets. A bracketed zero, as in +44 (0)20, is dropped, since it's never dialed from abroad. Extensions such as x23 or ext. 23 are removed and noted, because E.164 has no place for them.
  2. Look for a plus. A number with a plus already has its country code, so the default country is ignored.
  3. Look for an international prefix. It checks for the default country's exit code, such as 011 in the US and 00 in most of Europe, and for 00 and 011 in general, since lists often mix them.
  4. Try it as a national number. It removes the country's national prefix if there is one, such as the 0 in the UK or the 8 in Russia, and checks the digit count. Italy has no national prefix in this sense, so its leading 0 stays.
  5. Check for a forgotten plus. If the number starts with the default country code and the rest has the right length, as in 442079460958 with the UK selected, it's read as already international.

Order matters. In Japan, for example, 011 is the area code for Sapporo rather than an exit code, so with Japan selected, 011-123-4567 is read as a national number. The same digits would mean something else in the US.

How far can you trust the validity hints?

They're length checks, and that's all. “Length fits” means the digit count matches a landline or mobile length in that country. “Check” means the length exists only for special numbers such as toll-free or premium lines, so it may be a typo. “Invalid” means no number in that country has that length, or the number breaks a basic rule, such as a +1 area code starting with 0 or 1.

The country list and length ranges come from Google's open-source libphonenumber metadata, fetched in November 2026. Numbering plans change, and some countries, Germany among them, allow a wide range of lengths, so a pass there says little. Argentina is a known tricky case: its mobile numbers need a 9 after +54 in E.164, which you can't work out from length alone.

Questions

What is E.164 format?
E.164 is the international phone number format: a plus sign, the country code, then the national number, with no spaces or punctuation. It has 15 digits at most, and the first digit after the plus is never 0. A US number looks like +14155550100.
What's the US phone number format for Twilio?
+1 followed by the 10-digit number, with no spaces, dashes or brackets. So (415) 555-0100 becomes +14155550100. Twilio's APIs expect this form in the To and From fields.
Should I keep the leading 0 of a UK number?
No. The 0 is a national prefix used only when dialing inside the UK, so 020 7946 0958 becomes +442079460958. Italy is the main exception people run into: there the 0 is part of the number and stays, as in +390669821234.
Are my phone numbers uploaded anywhere?
No. The formatting happens in your browser using code that's already on this page. The site's security policy also blocks connections to other servers, and numbers are never saved or added to the URL. Only your default country is kept in the URL.
Does a valid result mean the number works?
No. This tool checks the format and whether the digit count fits the country's numbering plan. It can't tell whether a number is in service, or whether it's a mobile. A lookup service, such as Twilio Lookup, can tell you more.
Why does Excel remove the plus sign from my CSV?
Spreadsheets treat +14155550100 as a number and may drop the plus or show it in scientific notation. Import the file with the e164 column set to Text instead of opening it directly. The CSV from this tool has the correct value, so check it in a text editor if in doubt.
