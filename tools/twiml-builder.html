What does this TwiML builder do?

It writes the XML for you. Add verbs from the list, reorder them with the arrows, and fill in their options. Every attribute comes with its allowed values and defaults, taken from Twilio's docs for each verb, so you don't have to keep a tab open. For more patterns to adapt, see our TwiML examples guide.

The builder handles the fiddly parts. Text and attribute values are XML-escaped, so an ampersand in a company name won't break the document. Gather accepts nested Say, Play and Pause. Dial takes nested Number blocks, with extension digits and answering machine detection under More options. The counter shows how much of the 4,000-character inline limit you've used.

How the TwiML validator checks your document

Paste a document in the checker at the bottom of the tool. A small parser written for this page reads it with no network access and no browser XML engine, so it can give you line numbers and plain explanations rather than a generic parse error. It catches:

  • Broken XML, such as mismatched tags, missing quotes and a raw & that should be &amp;.
  • A root element other than Response, and text placed directly inside Response.
  • Wrong capitalization, since TwiML is case-sensitive: numdigits fails, and numDigits works.
  • Attributes a verb doesn't have, and values it doesn't allow, such as a Dial timeout outside 5 to 600.
  • Verbs in the wrong place, such as Dial inside Gather or Number outside Dial.
  • Phone numbers that aren't in E.164. The E.164 formatter fixes those in bulk.
  • Verbs that can never run, because they come after Hangup, Redirect or a Dial with an action.
  • A Say over its voice's character limit, and a document over the 4,000-character inline limit.

Verbs beyond the ones the builder edits, such as Connect, Enqueue, Pay and Reject, are accepted with a note, and their attributes aren't checked. Press “Load into the builder” to keep editing what you pasted.

Worked example: press a key to connect, with no server

A problem with click-to-call is that a voicemail or call screener can answer your phone and trigger the second call, leaving the other person connected to nothing. The fix is to ask for a key press first, since a voicemail box won't press one. The difficulty is that Gather sends its result to a URL, which usually means running a server.

Because the second document is percent-encoded into a URL, it's hard to edit by hand. The builder shows a decoded version below the action field, so change the caller ID and number there and the URL updates. The template comes to about 540 characters on one line, well inside the inline limit. Keep in mind that this call bills as two legs, which the Twilio pricing calculator can show you. This is the same approach Dialbubble uses for its Talk calls.

Where do you use the TwiML once it's built?

Paste the readable version into a TwiML Bin in the Twilio Console, or return it from your own web server with an XML content type. Use the one-line version for the Twiml parameter when you create a call through the API. To forward calls to your cell phone with this tool's Dial template, see Twilio call forwarding. For recording options, the call recording guide goes further. You can also find what a failed call's error code means in our list of Twilio errors.

Questions

What is TwiML?
TwiML is the XML that tells Twilio what to do on a call. A document has one Response element containing verbs such as Say, Play, Gather and Dial, and Twilio runs them from top to bottom. When it reaches the end, the call hangs up.
What's the TwiML character limit?
Twilio's Calls API takes at most 4,000 characters in its Twiml parameter, so inline TwiML has to fit that. TwiML served from a URL isn't subject to that parameter limit. Say has its own limits, depending on the voice: 3,000 characters for Amazon Polly, and 5,000 for Google and ElevenLabs voices.
Does this tool test my TwiML on a real call?
No. It checks the XML and compares verbs, attributes and allowed values with Twilio's docs, all in your browser. It can't tell whether a URL works or whether your account may use a caller ID. Place a test call before relying on it.
Which verbs can go inside Gather?
Say, Play and Pause. Anything else inside Gather is invalid, and Twilio also doesn't allow the digits attribute on a Play inside Gather. If you need to dial after a key press, do it in the TwiML at the action URL, which is what the press a key template does.
What's the Echo Twimlet?
It's a small service from Twilio Labs, at twimlets.com/echo, that returns whatever TwiML you put in its Twiml query parameter. It lets you have a follow-up step, such as the action of a Gather, without running a server. The TwiML sits in the URL, so don't put anything secret in it.
Do I have to include the XML declaration?
No. Twilio's examples include it, and the readable output here does too, but the one-line output leaves it out to save characters. What matters is that the root element is Response, since Twilio treats any other structure as invalid.
