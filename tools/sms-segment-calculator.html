What is an SMS segment?

An SMS segment is the unit carriers actually send and Twilio actually bills. A single SMS can carry only 140 bytes, so a longer message is cut into pieces that your recipient's phone stitches back together. It usually looks like one message on the screen, but on your bill it's several. If you want the full background, read our guide to GSM-7 and UCS-2 encoding.

How this SMS character counter works

The calculator follows the same steps as the network.

  1. It picks the encoding. If every character is in the GSM 03.38 alphabet, the message goes as GSM-7, at 7 bits a character. If even one isn't, the whole message goes as UCS-2, at 16 bits a code unit. You can browse the alphabet in the GSM-7 character checker.
  2. It counts units. A normal GSM-7 character is one unit. The ten characters in the extension table, including the euro sign and square brackets, are two. In UCS-2, most characters are one unit and those outside the basic plane, such as most emoji, are two.
  3. It decides whether the message splits. Up to 160 GSM-7 units or 70 UCS-2 units fit in one segment. Beyond that, each segment holds 153 or 67, since each one now carries a header.
  4. It packs the segments. A character is never cut in half. If an emoji's two units or a euro's escape sequence would straddle the boundary, the whole character moves to the next segment and the previous one is left a unit short.

That last step is why simple division can be wrong. A GSM-7 message of 306 units looks like exactly two segments, but if a euro sign lands on the boundary, it needs three. The bars under each bubble above show how full each segment is, so you can see this happen as you type.

Worked example: one apostrophe, three times the price

Take the message that's loaded above when you open this page. It's a 137-character appointment reminder with one curly apostrophe in “it's”, which word processors and phone keyboards add automatically. The curly apostrophe isn't in GSM-7, so the message goes as UCS-2. At 67 units per segment, 137 units take three segments: 67, 67 and 3.

Press “Replace smart punctuation” and it becomes a straight apostrophe. Now the message is GSM-7, and 137 is under the 160 limit, so it fits in one segment. Sent to 1,000 US recipients at the $0.0083 list price with a $0.0045 carrier fee, that one character is the difference between $38.40 and $12.80. You can put those numbers in the Twilio pricing calculator to see the effect on a whole month.

Do toll-free numbers have different limits?

Slightly. Twilio's glossary says that multi-segment messages sent from toll-free numbers to the US or Canada hold 152 GSM-7 characters or 66 UCS-2 characters per segment. The single-segment limits don't change. Tick the toll-free box above to use those numbers.

How to reduce your SMS segments

  • Paste from a plain text editor, or use the replace button, so smart quotes, long dashes and ellipses don't slip in.
  • Use emoji only where they earn their cost. One emoji can take a message from a 160 limit to a 70 limit.
  • Watch out for accented letters. Some, such as é and ñ, are in GSM-7, while others, such as á and ç, aren't. The tool can remove accents, but check the result still reads correctly.
  • Avoid square brackets, curly braces and the euro sign when you're close to a limit, since each counts double.
  • Shorten links and sign-offs. They're often the easiest place to find spare characters.

Long messages can also be filtered more often by carriers. If a text isn't arriving, our guide to fixing Twilio error 30007 covers carrier filtering, and how Twilio SMS works explains the rest of the path a message takes.

Questions

How many characters are in one SMS segment?
160 characters in GSM-7 and 70 in UCS-2 when the message fits in a single segment. Once a message has to split, each segment holds 153 GSM-7 characters or 67 UCS-2 code units, because part of each segment carries the header that lets the phone join them back together.
Why does my 100-character message count as two segments?
It almost certainly contains a character outside GSM-7, such as a curly apostrophe pasted from a word processor or an emoji. That one character sends the whole message as UCS-2, where the limit drops to 70. Paste it above, and the tool marks the character responsible.
How many segments does an emoji use?
An emoji doesn't use segments by itself, but it does switch the message to UCS-2 and usually costs two code units. Flags cost four. Joined emoji such as a family cost more, since each person and joiner counts. So 35 simple emoji fit in one segment, and the 36th starts a second.
Does the euro sign count as two characters?
Yes, in GSM-7. The euro sign and the characters ^ { } \ [ ] ~ and | live in the extension table, so each one takes two characters' worth of space: an escape code and the character itself. In a UCS-2 message, they count as one like anything else.
What's the maximum length of a Twilio SMS?
Twilio documents a limit of 1,600 characters for a message body. Long messages still bill for every segment, and this tool warns you past that limit. Twilio's glossary shows a lower figure of 700 for UCS-2 messages in one table, so keep Unicode messages well under 1,600.
Do I pay per message or per segment?
Per segment. A message that splits into three segments costs three times the per-segment price, and the same goes for each recipient. Received messages are billed by segment too.
