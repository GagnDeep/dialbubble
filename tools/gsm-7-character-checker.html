What is GSM-7?

GSM-7 is the default character set for text messages. It fits each character into 7 bits, which is how 160 characters fit in a single SMS. The set is defined in a standard known as GSM 03.38, now maintained as 3GPP TS 23.038. It's far smaller than the set of characters your keyboard can type, and that gap is what catches people out.

A character outside the set can't be sent in GSM-7, so the phone network switches the entire message to UCS-2, a 16-bit encoding. There's no mixing within a message. One odd character changes the limit for all the others, from 160 to 70. The practical effect on your bill is covered in the SMS segment calculator and our guide to GSM-7 vs UCS-2.

How to read the GSM 03.38 table

The table above has 128 cells, one for each 7-bit value. Read the column and then the row to get a character's code: the column labeled 4x and the row labeled x1 give 0x41, which is a capital A. Some cells aren't printable. LF is a line feed, CR is a carriage return, SP is the space and ESC is the escape code at 0x1B.

The escape code is the door to the extension table. When a phone reads ESC, it looks up the next value in that second table. This is how the euro sign, square brackets, curly braces, the backslash, the caret, the tilde and the vertical bar get in. It's also why they count double: they take two 7-bit values, one for ESC and one for the character. The form feed at 0x0A works the same way, though you'll rarely meet one.

The standard also defines national shift tables for languages such as Turkish, Spanish and Portuguese, which swap in other characters. This checker uses only the default alphabet and its default extension table, because those are what a message can count on everywhere.

Worked example: a short message that isn't GSM-7

The sample above reads like plain English: “We're open today, see you at 10”, with a dash and a trailing ellipsis. It has three characters outside GSM-7, all easy to miss: the curly apostrophe (U+2019), the en dash (U+2013) and the single-character ellipsis (U+2026). Each is highlighted in the text and listed below it with what can replace it.

Press “Replace smart punctuation” and they become a straight apostrophe, a hyphen and three dots. This short message fits one segment either way, but the same three characters in a 150-character message would change the result from one segment to three. Long messages and message templates are where this check pays for itself, so run your templates through it once and save the clean versions.

Which characters most often break GSM-7?

  • Smart punctuation. Curly quotes, en and em dashes, and the ellipsis. Word processors and phone keyboards produce these on their own. The one-click replacement handles all of them.
  • Invisible characters. Non-breaking spaces and zero-width spaces come along when you copy from web pages and documents. You can't see them, but the checker marks them, and the replacement removes or swaps them.
  • Accented letters. GSM-7 includes some, such as é, è, ñ, ü and à, but not others, such as á, í, ó, ú and ç. There's no automatic fix here, because changing a letter can change a word. The segment calculator offers an optional button to remove accents.
  • Emoji and symbols. These have no GSM-7 form at all. Decide whether each is worth the shorter limit.
  • Backticks. A ` isn't in GSM-7, even though it sits on most keyboards. The replacement swaps it for a straight apostrophe.

Questions

What are GSM characters?
GSM characters are the set a standard text message can send at 7 bits each. The GSM 03.38 default alphabet has 128 positions covering English letters, digits, common punctuation, some accented letters and a few Greek capitals. Ten more characters are available through an extension table.
Is an apostrophe a GSM-7 character?
The straight apostrophe (') is. The curly apostrophe (’) that phones and word processors insert isn't, and it's the most common reason a plain-looking message sends as UCS-2. The two look nearly the same, which is why a checker helps.
Are emoji GSM-7 characters?
No. Every emoji is outside GSM-7, so one emoji sends the entire message as UCS-2. That cuts a single segment from 160 characters to 70.
Which currency symbols are in GSM-7?
The default alphabet has the dollar, pound and yen signs, plus the generic currency sign. The euro is in the extension table, so it counts as two characters. Others, such as the cent sign and the rupee sign, aren't in GSM-7 at all, so one of them sends the message as UCS-2.
Are lowercase Greek letters in GSM-7?
No. The alphabet has only the Greek capitals that don't look like Latin letters, such as Δ, Φ and Ω. Lowercase Greek letters send the message as UCS-2.
Does replacing smart punctuation change what the reader sees?
Only slightly. Curly quotes become straight ones, long dashes become hyphens, and an ellipsis becomes three dots. Letters and emoji aren't touched, so the meaning stays the same. Read the result before you send it, since three dots do use three characters rather than one.
