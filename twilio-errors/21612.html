Twilio error 21612: To and From can't pair

Twilio error 21612 means this particular pairing of From and To can't work, even if each number is valid on its own. Country rules, network limits on sender types, or a missing carrier connection are the usual reasons.

What does Twilio error 21612 mean?

Twilio's name for it is Message cannot be sent with the current combination of "To" and/or "From" parameters.

The key word is combination. The same sender may reach other recipients, and the same recipient may accept other senders. So don't start by assuming either number is broken.

Twilio's own advice is to check the country's SMS guidelines and try a different pairing. That's also the fastest way to narrow it down.

Most likely causes, in the order to check them

  1. The destination country limits which numbers, short codes or sender IDs can send there.
  2. The destination network doesn't accept that sender type, such as short codes, or long codes from another country.
  3. The alphanumeric sender ID isn't supported in that country, or isn't pre-registered where it must be.
  4. One of the numbers isn't in E.164, so Twilio changed it in a way you didn't expect.
  5. Twilio has no connection to that carrier yet.

How to fix Twilio error 21612

  1. Rewrite both numbers in E.164 and resend. It's the quickest thing to rule out.
  2. Send from a different sender to the same recipient. If that works, the first sender type is the issue.
  3. Send from the same sender to another recipient in that country. If that fails too, it's the country or route.
  4. Read Twilio's SMS guidelines for that country, and check whether your sender ID is supported and registered.
  5. Use Twilio Lookup to see which network the recipient is on.

How to prevent it

  • Choose senders per country, ideally a local number where the rules ask for one. A regulatory bundle may be needed.
  • Use a Messaging Service with several sender types, so Twilio can pick one that works.

Are you billed for error 21612?

Billing

As of November 2026, a message that ends as Failed can carry Twilio's $0.001 failed-message fee. Retrying the same pair won't help, so change something first.

Questions about 21612

Can a US number text any country?
Not always. Many countries restrict foreign long codes, and you'll need to check each country's guidelines. Your Geo Permissions must allow it too.
How do I tell 21612 from 21408?
21408 means your own account settings block the country, and you can change that. 21612 means the pairing doesn't work on the route, regardless of your settings.
